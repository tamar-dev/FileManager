# Roadmap

## Principle
Roadmap items must reinforce FileManager as a metadata-driven file management engine, not a search engine.

## Phase 1 - Foundation
- Stable metadata schema and persistence
- Initial indexing + change monitoring separation
- Reliable filesystem synchronization
- Basic virtual folders and tags

## Phase 2 - Organization Features
- Multi-folder logical association for a single file
- Smart collections
- Duplicate detection pipeline
- Photo-library oriented metadata improvements

## Phase 3 - Performance & Modularity
- Replaceable indexing strategies behind Core contracts
- Background workers (hashing, thumbnail generation)
- Incremental update optimizations
- Memory/cache access layer for frequent queries

## Phase 4 - Advanced Engine Capabilities
- Collection/query engine enhancements
- Thumbnail cache lifecycle management
- Operational diagnostics and resilience improvements
